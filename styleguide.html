BBG Electrical: homepage style guide

This guide covers only what index.html implements today. Every component below is live markup copied from the homepage and styled by the site's own, unchanged stylesheets: src/tailwind.css and src/styles/*.scss. Values come from the source files and were confirmed with computed styles in Chromium at 390 px (mobile) and 1440 px (desktop). 768 px and 1024 px were checked for the in-between breakpoints. Media queries respond to the browser width, so each live example shows the layout for your current window. The tables give mobile and desktop values side by side.

Breakpoints

Two systems set breakpoints: hand-written Sass media queries and Tailwind's responsive prefixes. Many sizes are also fluid via clamp(), so they scale continuously between breakpoints.
